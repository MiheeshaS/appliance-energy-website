ABOUT THE PROJECT

About EnergyWise

A demonstration website for exploring appliance energy consumption in Australia, with a focus on television energy use and informed consumer choices.

OUR PURPOSE

Making Energy Information Easier to Understand

EnergyWise is an educational demonstration website focused on appliance energy consumption in the Australian market.

The website provides a simple way to present appliance energy information, with a focus on television energy consumption and insights relevant to Australian consumers.

This project demonstrates how HTML, CSS and JavaScript can work together to create a clear, responsive and interactive website.

WEB TECHNOLOGIES

How This Website Was Built

The project uses three core front-end technologies to provide structure, styling and interaction.

HTML

HTML provides the structure and content of the Home, Televisions and About Us pages.

CSS

CSS controls the colours, spacing, layouts, hover effects and responsive design of the website.

JavaScript

JavaScript provides page navigation and interactive features such as the television energy calculator.
